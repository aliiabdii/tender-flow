# TenderFlow – AI-Powered B2B Tender Management API

A BackEnd-only REST API for automating tender management in a B2B company.

Implemented with the help of GitHub Copilot CLI using GPT-6.1-Sol model and [Superpowers](https://github.com/obra/superpowers) skill set.
